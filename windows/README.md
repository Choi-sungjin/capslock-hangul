# Windows 개발 계획

**아직 구현하거나 설치하지 않았습니다.** Linux용 실행 파일과 설치 스크립트는 Windows에서 사용할 수 없습니다.

목표는 Linux와 같은 키 동작입니다: 짧은 Caps Lock은 한국어 IME 한영 전환, 300ms 이상은 대문자 고정, 기존 한영키 자리는 오른쪽 Alt. 로그인 시 자동 실행하며 종료·제거·기존 설정 복원이 가능해야 합니다.

구현 전에 확인할 항목:

- Windows 버전, Microsoft 한국어 IME, 실제 키보드의 전용 한영키/오른쪽 Alt 입력 코드.
- 짧게·길게·경계 입력·겹쳐 누르기·반복 입력·Alt 조합키.
- 일반 앱, 관리자 권한 앱, 잠금/해제, 재부팅 뒤 로그인 시 동작.
- 로그인 화면부터 지원할지, 사용자 로그인 이후부터 지원할지 명확한 지원 범위.

구현 방식은 Windows 환경과 기존 도구를 검토한 뒤 결정합니다. 실제 Windows에서 확인하기 전에는 지원 완료로 표시하지 않습니다.
